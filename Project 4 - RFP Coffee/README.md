# Project 4: RFP Coffee Network Design

## Scenario
RFP Coffee is a small business that needs a secure, scalable network design for multiple departments and internet access.

## Requirements
- Department segmentation
- Internet access through NAT
- Dynamic routing
- Secure access between VLANs
- Server/printer support
- Documentation for handoff

## Technologies Used
- VLANs
- Static routes
- EIGRP
- NAT
- ACLs
- DHCP
- DNS
- Cisco Packet Tracer

## Final Deliverables
- Network topology
- IP addressing table
- Device configurations
- Routing verification
- NAT verification
- Security policy summary
- Troubleshooting notes
